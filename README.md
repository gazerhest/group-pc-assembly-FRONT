# PC Assembly — Frontend

## Команда
- Соловей Данило
- Погрібний Володимир

## Опис
Клієнтська частина вебплатформи для підбору комп'ютерних комплектуючих та створення оптимальних збірок ПК. Інтерфейс розв'язує проблему складності вибору «заліза» для геймерів, розробників і звичайних користувачів, надаючи зручний інтерактивний конструктор збірки, миттєву перевірку сумісності компонентів, модуль порівняння та експорт специфікацій.

## Ролі користувачів
- **Гість:** перегляд каталогу деталей із фільтрацією та сортуванням; перегляд детальних характеристик комплектуючих; перегляд публічних збірок інших користувачів; порівняння параметрів деталей.
- **Авторизований користувач:** усі можливості гостя + поетапне створення, збереження та редагування власних конфігурацій ПК; автоматична перевірка збірки на сумісність; додавання товарів у кошик та оформлення замовлення (комплектуючі та послуга збірки); публікація або шеринг збірки за посиланням; експорт специфікації збірки.
- **Адміністратор:** усі можливості користувача + повне керування каталогом (додавання, редагування, видалення категорій, виробників і комплектуючих через форми); керування замовленнями та зміна їхніх статусів.

## Основний функціонал
- **Каталог комплектуючих:** динамічний рендеринг карток товарів (назва, категорія, виробник, характеристики, ціна, рейтинг), миттєвий пошук у реальному часі та гнучка фільтрація.
- **Детальна сторінка комплектуючого:** повні технічні характеристики (сокет, TDP, форм-фактор, тип пам'яті тощо), відгуки та рейтинг від покупців.
- **Модуль порівняння:** вибір кількох деталей однієї категорії та наочне порівняння їхніх характеристик у спільній таблиці.
- **Інтерактивний конструктор збірки:** покроковий вибір компонентів із миттєвим перерахунком сумарної вартості, індикатором енергоспоживання та статусом сумісності.
- **Особистий кабінет:** форми входу та реєстрації (JWT-токени), керування збереженими збірками (приватні/публічні), історія замовлень та редагування профілю.
- **Панель адміністратора:** адаптивний інтерфейс для модерації каталогу та керування статусами замовлень користувачів.

## Особливість проєкту 
1. **Алгоритм валідації сумісності (Compatibility & TDP Engine):**
   - Перевірка сумісності процесора та материнської плати за сокетом (наприклад, AM5, LGA1700).
   - Валідація підтримки покоління оперативної пам'яті (DDR4 / DDR5) материнською платою.
   - Калькулятор потужності: підрахунок сумарного TDP системи та рекомендація мінімально необхідної потужності блока живлення (із безпечним запасом 20%).
2. **Модуль наочного порівняння компонентів:**
   - Інтерактивне зіставлення технічних характеристик кількох деталей однієї категорії у зведеній таблиці з виділенням ключових відмінностей.
3. **Шеринг та експорт збірок (Shareable Links & Export):**
   - Генерація постійного посилання на збірку для зручного обміну з друзями без необхідності обов'язкової реєстрації отримувача.
   - Експорт готової специфікації збірки з повним списком деталей та підсумковою вартістю для друку або покупки.
